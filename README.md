# The Rosary Through Time — static export

Upload the extracted website files and folders (including index.html at the root) to your GitHub Pages publishing directory or other static host. Keep assets/ and vendor/ alongside index.html. The project-source/ folder contains maintenance scripts, provenance and implementation reports; it is not needed to run the website.

The supplied Track 1 is included at assets/track-1.mp3. The soundtrack starts after an eligible visitor gesture, subject to browser policy. Play/Pause, Mute and Volume are available through the music icon. For a Squarespace iframe, use your deployed HTTPS URL and allow="autoplay; fullscreen"; actual playback still requires an eligible interaction and browser permission. No third-party music upload is needed.

Sources & Artwork Notes opens in-place. The canonical sources.html resource must remain alongside index.html. Native phone gestures and GPU performance require device testing; see project-source/REFINEMENT-11.md.
