# NASA Earth textures — recovered assets

Primary record: https://svs.gsfc.nasa.gov/4439/ — High Resolution Layers from “Monsoons: Wet, Dry, Repeat...”, released June 23, 2016.

Original sources:
- Land: https://svs.gsfc.nasa.gov/vis/a000000/a004400/a004439/flat_bluemarble_8192x4096.tif
- Ocean: https://svs.gsfc.nasa.gov/vis/a000000/a004400/a004439/flat_ocean_8192x4096.tif

Credit: NASA’s Scientific Visualization Studio.

The original land alpha channel was composited over the accompanying NASA blue ocean layer. Land imagery includes seasonal snow; the ocean is uniform visualization color, not a bathymetric map. No coastlines, geographic features or terrain were generated. These are historical composite data, not current satellite imagery.

- earth-daylight-hires.jpg: native 8192×4096, JPEG quality 92, progressive, 4:4:4. Approximately 128 MiB RGBA8 base texture / 170.7 MiB with a complete mip chain. About 4.9 km per equatorial texel.
- earth-daylight-regional.jpg: 4096×2048, downsampled directly from the original composited 8K TIFF layers using Lanczos, same JPEG settings. Approximately 32 MiB RGBA8 base / 42.7 MiB with mipmaps. About 9.8 km per equatorial texel.

Suitable for country/regional globe exploration, not street or building detail. Keep the existing 2K fallback and load higher-resolution tiers only on capable devices.
