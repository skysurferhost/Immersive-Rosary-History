# Music controls

Open Music controls (the musical-note button) or Settings. Play/Pause, Mute/Unmute and independent volume are available; default volume is20%. Playback requires a user gesture. The default is an original16-note contemplative instrumental sketch synthesized with gently enveloped melody and changing triadic accompaniment, replacing the previous unchanging four-tone drone. It is not a liturgical chant or a supplied recording.

No designated MP3/WAV/OGG/M4A recording was present in the uploads or project assets. “Use your music file” accepts a local recording for the current visit without uploading it. It loops with a1.5second fade near both endpoints. This does not promise gapless browser decoding. To make a designated recording the permanent default, add the licensed file to assets and set source in dist/music-config.js to its relative path. Music never starts automatically.
